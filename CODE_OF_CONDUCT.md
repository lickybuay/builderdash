# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and focus on the work.
Harassment, insults and personal attacks are not tolerated in issues, pull requests,
discussions or any other project space.

To report unacceptable behaviour, contact the maintainer privately through
[GitHub](https://github.com/lickybuay). Reports are handled confidentially.
